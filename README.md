# A股量价雷达

一个无需本地安装即可运行的 A 股交互式观察页面。

## 已实现

- 东方财富实时指数、行业板块和概念板块数据
- 自动读取当日涨幅靠前的 5 个热门板块，并去重
- 每个热门板块扫描 3–5 只候选股票
- 日 K、5/15/30/60 分钟 K 线及 MA5/MA10/MA20
- 当日成交量、成交额、3 日均量、10/20 日涨幅
- 10/30 日技术偏离率、量比与量价结构评分
- 放量突破、缩量回踩、弱转强、放量滞涨识别
- 公司公告关键词初筛；接口异常时提供官方核对链接
- CSV 观察清单导出
- 北京时间 01:00 前一日复盘、12:00 午间快照

## 数据口径

行情首选东方财富公开接口。页面不使用虚构价格；数据请求失败时会显示错误状态。页面中的“10/30 日偏离”是股价相对 10/30 日均价的技术偏离率，不等于交易所监管公告中的涨跌幅偏离值。

## 定时任务

.github/workflows/market-report.yml 会运行 scripts/update_report.py，将快照保存到 data/latest.json 和 reports/。GitHub Actions 使用 UTC：

- 17:00 UTC：对应次日北京时间 01:00
- 04:00 UTC：对应北京时间 12:00

也可以在 Actions 页面手动运行并选择报告类型。

## 发布

.github/workflows/deploy-pages.yml 在 main 分支更新时自动发布 GitHub Pages。若首次发布失败，请在仓库 Settings → Pages → Build and deployment 中选择 GitHub Actions，然后重新运行工作流。

## 风险提示

本项目用于行情整理和量价结构教学，不构成证券投资建议。公开行情接口可能延迟或调整，交易前应以交易所、上市公司正式公告及持牌行情终端为准。
